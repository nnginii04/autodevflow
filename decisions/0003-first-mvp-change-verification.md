# ADR-0003: 첫 MVP를 변경 영향도 분석과 변경 후 검증으로 선정

- 상태: 채택
- 날짜: 2026-11-24
- 관련: [docs/01-work-analysis.md](../docs/01-work-analysis.md) 7장, 10장, 12장

## 배경

업무 분석서에서 세부 업무 49개를 기능 후보 13개(F1~F13)로 묶어 효과, 난이도, 위험, 검증 가능성을 평가했습니다.

## 선택지

1. 요구사항 품질 검사(F6): 난이도는 낮지만 상용 ALM에 이미 있어 차별화가 낮음
2. 시험 케이스 생성(F7): 실무 활용도는 높지만 상용 ALM에 이미 있음
3. 변경 영향도 분석 + 변경 후 검증 + 버전 일관성 + 링크 후보 + 시험 결과 연동(F1~F5): 난이도는 높지만 Pain Point P1~P4의 공통 원인을 다루고 검증 가능성이 높음

## 결정

3번을 첫 미니 프로젝트 **Change & Verification Intelligence**로 채택하고, 가상 자동 전조등 제어 기능을 대상으로 합니다.

## 이유

- P1~P4가 모두 "산출물 간 연결과 버전"이라는 같은 원인에서 나옵니다.
- 통제된 변경을 주입하면 영향 산출물 정답을 미리 정의할 수 있어 정량 평가가 가능합니다.
- 자동 전조등은 작지만 임계값, 비교 연산, 히스테리시스, 타이머, 모드 전이, 센서 오류 처리를 모두 담아 변경 유형 10종을 만들 수 있습니다.
- 여기서 만드는 Artifact Registry, Trace Graph, Version & Baseline, Evidence Store는 이후 모든 모듈이 공유합니다.

## 영향

- 설계 초안 생성(F13)은 보류합니다. 자동차 설계는 모델 기반이 많아 텍스트 초안의 가치와 검증 가능성이 낮습니다.
- MVP 범위와 인수 기준은 업무 분석서 12장을 따릅니다.
- SUP.10 중 기술적 영향도 분석만 다루며, 비용·일정·위험 평가는 범위 밖입니다.
