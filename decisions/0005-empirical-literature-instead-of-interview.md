# ADR-0005: 현업 인터뷰 대신 실증 문헌으로 업무 분석 검증

- 상태: 채택
- 날짜: 2026-11-26
- 관련: [docs/01-work-analysis.md](../docs/01-work-analysis.md) v1.1 0장, 7장, 11장

## 배경

업무 분석서 v1.0은 Pain Point 11개 중 10개를 가설로 두고, 11장에서 현업 인터뷰(Q1~Q12)로 확인할 계획이었다. 그러나 현재 현업 인터뷰를 진행할 수 없는 상황이어서, Milestone 01을 인터뷰 일정에 묶어 둘 수 없다.

## 선택지

1. 인터뷰가 가능해질 때까지 대기: 일정이 불확실하고 이후 산출물이 모두 밀림
2. 가설 상태 그대로 진행: 업무 분석서의 근거가 약하고, MVP 선정 이유를 설명하기 어려움
3. 실무자를 직접 인터뷰하거나 설문한 학술 연구(실증 문헌)로 대체: 현업 데이터를 간접적으로 활용할 수 있고 출처를 검증할 수 있음

## 결정

3번을 채택한다.

- 근거 수준에 **실증 문헌**(실무자 인터뷰, 설문, 사례 연구 기반 논문)을 추가하고, 기법 제안 논문과 구분한다.
- 11장을 "현업 확인"에서 "실증 문헌 검증"으로 바꾸고, 질문별로 확인 결과와 미확인 항목을 구분해 기록한다.
- 문헌으로 얻을 수 없는 빈도와 소요 시간은 계속 미확인으로 두고, MVP 효과 비교에 필요한 시간은 기준 데이터셋에서 직접 측정한 기준선으로 대체한다.
- 현업 인터뷰나 서면 응답이 가능해지면 선택적으로 보완하고, 해당 항목의 근거 수준을 현업으로 갱신한다.

## 이유

- 자동차 추적성(Maro 외 2017, 2018), 자동차 요구공학(Liebel 외 2018, Ågren 외 2019), 안전 필수 시스템 변경 영향도 분석(de la Vara 외 2016, Borg와 Alégroth 2017)에 관한 실증 연구가 있어, MVP와 직접 연결된 P1, P2, P3과 요구사항 관련 P5, P6을 뒷받침할 수 있다.
- 특히 변경 영향도 분석의 자동화 수준이 낮고 도구 지원 부족이 가장 흔한 과제라는 산업 설문 결과(유효 응답 97건)는 첫 MVP 선정(ADR-0003)의 근거를 강화한다.

## 영향

- 확인 결과: 부분 확인 4개(Q3, Q4, Q8, Q9), 간접 확인 1개(Q1), 미확인 7개.
- 인용 연구가 2016~2019년, 북유럽 기업 중심이라는 점과 일부 연구가 자동차 외 안전 필수 시스템을 포함한다는 점을 11장 타당성 위협에 기록한다.
- 이슈 `[작업] 현업 인터뷰 Q1~Q12 진행`은 `[작업] 실증 문헌으로 Pain Point 검증`으로 바꾸고, 인터뷰는 선택 항목으로 남긴다.
- Q5(설계 방식), Q11(AI 신뢰 조건)은 산출물 02에서 추가 조사한다.
