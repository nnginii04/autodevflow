# AutoDevFlow

> AI 기반 자동차 시스템 및 SW 개발 엔지니어링 자동화 플랫폼

자동차 시스템 및 소프트웨어 개발 과정에서 발생하는 반복적인 엔지니어링 업무를 자동화하고, 개발 산출물 간 정합성과 검증 가능성을 높이며, AI 적용 효과를 정량적으로 평가하여 실제 개발 프로세스 개선으로 연결하는 통합 플랫폼을 구축합니다.

AutoDevFlow는 자동차 SW를 자동으로 만들어 주는 도구가 아닙니다. 기존 ALM을 대체하지 않고, ALM과 연계하여 변경 요청의 의미적·구조적 영향을 분석하고 버전이 일치하는 개발 산출물과 시험 실행 근거를 바탕으로 요구사항 충족 여부를 검토하는 검증 계층을 목표로 합니다.

> 이 저장소의 모든 차량 사양(자동 전조등 등)은 연구용 **가상 사양**이며, 실제 차량이나 특정 회사의 자료가 아닙니다.

## 핵심 설계 원칙

1. **AI가 필요한 곳에만 AI를 사용합니다.** 비교, 탐색, 실행, 버전 확인처럼 결정론적으로 처리할 수 있는 작업은 일반 소프트웨어로 구현합니다.
2. **AI의 판단, 검증 도구의 실행 결과, 엔지니어의 승인을 분리합니다.** AI 출력은 항상 제안(PROPOSED) 상태로 들어가며 승인 후에만 확정됩니다.
3. **근거가 없거나 버전이 맞지 않는 판정은 신뢰하지 않습니다.** 근거가 부족하면 UNCERTAIN, 이전 버전의 시험 결과는 STALE로 처리합니다.
4. **효과는 숫자로 검증합니다.** AI를 쓰지 않는 비교 방식과 같은 조건에서 비교합니다.

## 저장소 구조

```text
autodevflow/
├── docs/              # 산출물 문서 (01~10)
├── decisions/         # 주요 결정 기록 (ADR)
├── retrospectives/    # 산출물별 회고
├── dataset/           # 가상 차량 사양, 기준 데이터셋, Gold Dataset
├── src/               # 플랫폼 소스코드
├── eval/              # 평가 스크립트와 결과
├── scripts/           # 저장소 운영 스크립트
└── .github/           # 이슈·PR 템플릿, CI
```
